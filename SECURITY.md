# Security policy

Please do not report suspected vulnerabilities or credentials in public issues.
Use GitHub's private vulnerability reporting for this repository, or contact the
maintainers through the private channel listed by the repository owner.

When reporting a security issue, include the affected version, operating system,
reproduction steps, and impact. Do not include live tokens, passwords, private
keys, OAuth secrets, or payment URLs in the report.

LibreGuard desktop builds must contain only public OAuth client identifiers.
